# RepairFlow Pro — Demo V0.1

Klikbare demo voor een reparatiezaak met:

- eigenaar-dashboard
- iPad klantenintake voor particulier, bedrijf en bestaande klant
- demo BTW/KBO-bedrijfsopzoeking
- reparatiedossiers met klantverklaring en foto-intake
- refurbished voorraad en marges
- SumUp/cash/overschrijvingsoverzicht
- CSV-export voor boekhouder
- klantenportaal met prijsgoedkeuring

## Vercel
Importeer repository `cma58/websites` in Vercel en stel **Root Directory** in op `repairflow-demo`.
Framework preset: `Other`.
Er zijn geen environment variables nodig voor deze demo.

Dit is een front-end demo zonder echte persoonsgegevens, database of live SumUp/KBO-koppeling.
